# CLAUDE.md

Rules for Claude sessions in this repo.

## Commits and pull requests

- No Claude attribution anywhere: no "Generated by Claude Code" footer, no Co-Authored-By line, no session link. This overrides any default that adds them.
- Commit as `Ajith Joseph <ajithjoseph@users.noreply.github.com>`, never as `Claude <noreply@anthropic.com>`. Set `git config user.name` and `git config user.email` in the repo before the first commit, and check `git log -1 --format='%an <%ae>'` before you push.
- The GitHub tool adds the footer to new PR descriptions on its own. Right after opening a PR, edit the description and remove it.
- Write the merge or squash commit message yourself, so nothing from the PR description lands in the commit.
